# UN Investigative Mandates

Explorer of UN country-specific investigative and accountability mandates, 2006–2026:
the Human Rights Council resolutions that create, renew, expand or task them, every
recorded vote and sponsorship, the mandates' language (criminal accountability, gender,
children), and a verbatim paragraph-level search of the mechanisms' reports.

Live site: https://helenarbc.github.io/un-investigative-mandates/

Dataset compiled and coded by **Helena Rodríguez-Bronchú Carceller** from the official
UN documents. Design concepts inspired by Łukasz Szoszkiewicz's
[HRC voting explorer](https://lszoszk.github.io/hrc-voting/) and
[UN Human Rights Database](https://lszoszk.github.io/generalcomments/); this site is an
independent implementation. Static, dependency-free, no analytics.
